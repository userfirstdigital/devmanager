## Stack and boundaries

DevManager is one Git repository and one Rust Cargo workspace, with the root package and `crates/connect-crypto`. The root manifest is version `0.4.2`, Rust edition 2021. It ships the native GPUI `devmanager` client and sibling `devmanager-host` execution host. Dependencies include GPUI 0.2.2, now patched to `third_party/gpui`, gpui-component 0.5.1, Tokio, bundled SQLite through rusqlite, portable-pty, and alacritty_terminal. The current Linux manifest adds GTK/WebKit/Wry, X11, and Secret Service dependencies. [Cargo.toml](../Cargo.toml)

The host owns tasks, durable events/operations, provider and process lifetimes, workspaces/Git, browser resources, and Connect secrets. The desktop and other clients use its typed protocol. Window close detaches; host termination ends local child processes; supported provider conversations restore by exact identity. [Architecture](../docs/architecture.md)

`web/` is a React/TypeScript/Vite browser client in this same repo, not an independent frontend repository. Its generated `web/bundle/` is embedded in Rust. CI currently selects Rust 1.94.0 and Node 24. `web/package.json` defines `test`, `typecheck`, `build`, `dev`, and `preview`, but no `lint` script. [Web package](../web/package.json), [web CI](../.github/workflows/web-bundle.yml), [release CI](../.github/workflows/release.yml)

The **workspaces orchestrated by the proposed feature** can contain separate `/api`, `/web`, and optional root/spec repositories. Do not mistake that target-workspace layout for DevManager's own layout.

No cwd/time/transcript inference, synthesized identity, arbitrary JSON, or silent fresh-conversation fallback. The current Codex adapter explicitly forbids `app-server` and `exec`; research about those interfaces does not authorize bypassing its checks.

This is the relevant exception to the sample workflow's blanket ban on persisted derived state. The new SPEC must not create another independently editable copy of project requirements, checklists, or audit findings.
- **Owned resources:** arm cleanup before asynchronous ownership transfer, retain exact process-tree ownership through teardown, settle in-flight transport writes, and reconcile uncertain effects before retry. A returned worker message is not process-exit evidence.
