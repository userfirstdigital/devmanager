# Remote integration acceptance

- A passing codec, in-memory Noise pair, or pre-authenticated socket is not a
  production remote-client gate. Exercise the actual listener's published host
  ID/key, HTTP pairing and Origin admission, greeting/prologue, Noise, assigned
  ClientId, Hello capabilities, and canonical query/command path together.
  Reconnect through that same route with retained trust and identity; never
  weaken publication or authorization fixtures just to make a client pass.
- Report command acceptance, physical provider delivery, and observed provider
  execution separately. A chat smoke must verify the exact submitted text,
  semantic assistant response, and correlated provider conversation ID, not
  merely an accepted receipt or settled PTY write. Keep all fixtures isolated
  from installed profiles and join their owned host/provider process trees.
