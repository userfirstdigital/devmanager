## Independent review correction pass

The correction pass stayed within the owned prompt/model/store, kernel schema,
focused test, fixture, and report paths. It added corrective migration V8,
`phase07-prompts-corrections-v2`, without changing V1-V7 SQL or checksums.

- Archived prompt rename/tag commands now reject in the command path, and the
  replay path rejects the same invalid metadata transitions.
- Idempotent prompt and chain receipts now require matching row keys, command
  IDs, targets, version/link IDs, revisions, valid UUID bytes, and exact
  canonical MessagePack bytes.
- Chain receipts/events are append-only at the V8 SQLite boundary. Projection
  rebuild validates event IDs, command receipt lineage, prompt/chain targets,
  event type, command/event time, payload contents, and canonical encoding;
  metadata event version lineage is checked at its replay point.
- `current_version_id` is runtime-validated against the latest immutable
  version, command execution fails closed on a stale pointer, and SQLite
  rejects rollback to an older version.
- Version-variable rows are created through an unsealed-then-sealed atomic
  sequence; later insertion is rejected and an unsealed version is reported as
  corruption. Identical CreateVersion content still creates the next version.
- SQLite enforces the truthful byte/scalar/trim boundaries, including the
  multibyte body boundary; Unicode normalization remains runtime-authoritative
  where SQLite cannot express the same rule.
- The upgrade matrix starts from every prior schema V1 through V7, upgrades to
  V8, then exercises create/edit/archive/restore/rebuild/reopen.
