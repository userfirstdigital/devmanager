- Added opaque UUIDv7 `PromptId`, `PromptVersionId`, `PromptChainId`,
  `PromptChainLinkId`, and `PromptHistoryId` exports.
- Added personal prompt commands, events, receipts, immutable versions, an
  explicit current-version foreign-key pointer, optimistic revisions, archive
  and restore tombstone semantics, and idempotent replay/projection behavior.
- Enforced title (160 Unicode scalars), description (2000), body (256 KiB
  UTF-8), tags (32 tags, 48 Unicode scalars each), and version variables (32
  normalized names, 64 Unicode scalars each) bounds.
- Kept version provenance append-only at both the store and SQLite trigger
  boundaries, including version-variable rows. Corrupt sparse positions,
  noncanonical event metadata, invalid hashes, foreign current pointers, and
  malformed records fail closed.
- Added deterministic, schema-framed named-MessagePack command/event codecs
  and fingerprints. Debug output redacts prompt bodies and validation errors
  do not include body content.
- Kept canonical title/body/tags/variables fields ready for later FTS work;
  Task 7.3 history/FTS, sync/org publishing, provider substitution, and
  automation/branching remain downstream work. Chain behavior is manual,
  explicitly ordered linking only.
- Added the `phase07-prompts-v1` migration tables, indexes, immutable triggers,
  schema partial-list entry, migration tests, prompt fixtures, and the focused
  model/store coverage.
