# Phase 3 Task 3.7 review round 5

Status: the Task 3.4 native terminal path now uses the Task 3.7 teardown
coordinator on Windows. The production terminal session no longer owns a
managed `ChildKiller` or drops a managed Job on close, restart, PTY error, or
child wait error.

## Correction

- `ManagedTerminalTeardown` is the native terminal host adapter. It registers
  the managed Job and receiver fence before a session becomes live, then
  routes close, restart, drop, reader error, and wait error through one exact
  Host ticket and coordinator.
- Setup failures after Job registration also use coordinator teardown. A raw
  `ChildKiller` remains only for the narrow pre-authority failure where Job
  attachment itself did not succeed.
- Synchronous terminal waiting uses a bounded condition-variable bridge on
  the waiter cell. It does not create a second runtime thread or an unbounded
  `join` in the terminal close path.
- Admission and executor shutdown share an atomic lifecycle fence. A request
  that races shutdown rolls back its exact receipt before publishing active
  work; new requests are rejected after the fence is set.
- Completion lookup and persistence, executor capacity and submission, and
  every effect/residue boundary check one absolute deadline before and after
  crossing the boundary. Monotonic deadlines retain nanosecond precision.
- Batch, retention, evidence, completion, and error collections are bounded.
- Managed Job/launcher modules and Job construction, attachment, completion
  drain, termination, and registry Job access are crate/host-only.

## Boundary note

The fixed executor still joins its fixed worker set during shutdown. This is
the safe no-orphan behavior: production workers accept only the private
host-issued adapters whose effect constructors are synchronous-safe and whose
futures are cancellation-safe at the shared deadline. Detaching a worker on a
timeout would violate the no-orphan invariant; an untrusted blocking adapter
must be moved to a killable helper process rather than installed at this host
boundary.
